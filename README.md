# 考研英语精读 (kaoyan-en-reading)

Daily bilingual English reading for 考研备考: Reuters / BBC excerpts with Chinese translations and vocabulary notes.

## Structure

- `index.html` — landing page listing daily readings
- `days/` — one HTML page per day (e.g. `days/2026-09-26.html`)

## Viewing

Open `index.html` or any file under `days/` in a browser. Public CDN example:

`https://cdn.jsdelivr.net/gh/asuka832/kaoyan-en-reading@main/days/2026-09-26.html`

Preview (htmlpreview):

`https://htmlpreview.github.io/?https://github.com/asuka832/kaoyan-en-reading/blob/main/days/2026-09-26.html`
